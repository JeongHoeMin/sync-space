팀 여러분, 현재까지의 작업 진행도를 검토한 결과 프론트엔드와 백엔드 모두 핵심 기반 기술의 뼈대가 성공적으로 구축되었습니다.

현재 백엔드(`app.gateway.ts`)는 Socket.io를 통해 JWT 기반 인증, 채널 입장(`join_channel`), 메시지 저장 및 전파(`send_message`) 로직이 구현되어 있습니다.
프론트엔드(`App.tsx`)는 Electron 환경의 화면 공유 소스 선택 로직, LiveKit Client를 통한 화상/음성 연결, 그리고 WebRTC DataChannel을 활용한 투명 캔버스 판서 동기화가 반영되어 있습니다.

성공적인 프로젝트 완성을 위해 프론트엔드 및 백엔드 개발자분들께 다음 진행 사항에 대한 기획 및 개발 계획서를 전달해 드립니다.

# SyncSpace 프로젝트 다음 단계 개발 기획 및 제안서

## 1. 프론트엔드 개발팀 (sync-space-app) 다음 진행 사항

현재 캔버스와 화면 공유라는 핵심 기능의 프로토타입이 완성되었으므로, 실제 서비스 환경에 맞춘 UI/UX 및 기능 고도화가 필요합니다.

- **인증 및 방 관리 대시보드 UI 구현:**
    - 데스크톱 앱 실행 시 가장 먼저 노출되는 로그인 및 회원가입 화면을 구현해야 합니다.
    - 로그인 성공 후 생성된 채널(방) 목록을 확인하고, 고유 접속 링크를 통해 채널에 입장하거나 새로운 채널을 생성하는 대시보드가 필요합니다.
- **LiveKit 및 인증 토큰 연동:**
    - 현재 `App.tsx` 내 `joinRoom` 함수에 더미 형태로 존재하는 토큰 발급 로직(`http://localhost:3000/livekit/token`)을 실제 백엔드 연동으로 교체해야 합니다.
    - 발급받은 JWT를 `Authorization` 헤더에 담아 인증된 사용자만 방에 접근할 수 있도록 통신 모듈을 구성해 주세요.
- **판서(Canvas) 기능 고도화:**
    - 현재 색상(`#ef4444`)과 굵기(`3`)가 하드코딩되어 전송되고 있습니다. 이를 사용자가 직접 선택할 수 있도록 색상 팔레트, 선 굵기 조절, 지우개, 그리고 화면 클리어 기능을 추가해 주세요.
- **채팅 및 파일 공유 패널 추가:**
    - 텍스트 채팅 및 이미지/파일 전송을 위한 사이드 패널 UI를 개발해야 합니다.
    - 드래그 앤 드롭으로 파일을 올리면 백엔드의 AWS S3 업로드 API를 호출하고 반환된 URL을 채팅창에 렌더링하는 로직을 추가해야 합니다.

## 2. 백엔드 개발팀 (sync-space-server) 다음 진행 사항

소켓 통신의 기본 구조가 잡혔으므로, 온전한 서비스 운영을 위한 REST API 구축과 소켓의 예외 상황 처리, 그리고 외부 스토리지(S3) 연동이 필요합니다.

- **인증 및 LiveKit REST API 구축:**
    - 이메일/비밀번호 기반의 회원가입 및 로그인을 처리하는 REST API(NestJS)를 구현하고 JWT를 발급하는 로직을 완성해야 합니다.
    - LiveKit Server와 연동하여 채널 접속을 요청하는 클라이언트에게 유효한 LiveKit 접속 토큰을 발급해 주는 API를 생성해야 합니다.
- **소켓 연결 해제(퇴장) 로직 구현:**
    - 현재 `AppGateway`의 `handleDisconnect` 내부가 비어있습니다.
    - 클라이언트가 소켓 연결을 끊었을 때, 데이터베이스의 참여자 목록(`channel_participants`)에서 상태를 갱신하거나 삭제하는 방 퇴장 처리 로직을 구현해 주세요.
- **AWS S3 파일 전송 파이프라인 구축:**
    - 사용자가 채팅창에 이미지 및 파일을 업로드할 수 있도록 AWS S3 업로드 파이프라인을 구축해야 합니다.
    - 파일 업로드 후 반환된 생성 URL을 클라이언트에 제공하여 Socket.io 채팅으로 전송될 수 있게 해야 합니다.

## 3. 개발 마일스톤 (단계별 계획)

기간 중심이 아닌 서비스의 논리적 완성 단계를 기준으로 한 개발 마일스톤입니다. 각 단계의 기능이 프론트/백엔드 모두 완료된 후 다음 단계로 넘어갑니다.

### **1단계: 인증 및 채널 입장 기반 통합 단계 (Authentication & Room Management)**

- **목표:** 사용자가 회원가입/로그인을 진행하고 본인의 채널을 생성 및 입장할 수 있는 완전한 플로우 구축
- **백엔드:** User 기반 JWT 발급 API 생성, 채널 생성/목록 조회 API 개발, LiveKit 접속 토큰 발급 API 구현.
- **프론트엔드:** 로그인/회원가입 폼 구현, 대시보드 UI 구현, 실제 JWT 및 LiveKit 토큰을 이용한 동적 `joinRoom` 연동.

### **2단계: 인터랙션 및 커뮤니케이션 고도화 단계 (Interaction & Communication)**

- **목표:** 화상/음성, 화면 공유, 판서, 채팅 등 앱의 핵심 가치 기능 완성
- **백엔드:** 소켓 접속 종료 시 채널 퇴장 예외 처리, AWS S3 연동 및 파일 업로드 API 구현, 메세지 저장 및 타입별(`TEXT`, `IMAGE`, `FILE`) 분기 검증 로직 보완.
- **프론트엔드:** 캔버스 상태 도구(색상, 굵기, 지우개) 개발, 텍스트 채팅창 및 파일 드래그 앤 드롭 전송 UI 통합.

### **3단계: 인프라 구성 및 배포 단계 (Infrastructure & Deployment)**

- **목표:** 실제 라이브 환경에 서비스 배포 및 쾌적한 앱 패키징
- **백엔드:** API 서버, PostgreSQL, LiveKit Media 서버를 Docker 및 Docker Compose로 패키징하여 Oracle Cloud 인스턴스 환경에 배포. Zod를 통한 모든 소켓 및 API 요청 검증 테스트 완료.
- **프론트엔드:** Electron 기반 빌드 체인 최적화, Mac/Windows OS용 데스크톱 애플리케이션 최종 패키징 및 배포 테스트.
